## 浏览器闭环

每个测试使用独立测试上下文，不读取真实账户或笔记：

1. 新建空白模拟笔记环境，加载真实 `dist/main.js`。
2. 从文件输入导入 HTML，验证两份附件（原件、工作件）和宿主 Embed 数据。
3. 验证默认显示 iframe，没有源码编辑器；点击 HTML 内按钮可运行脚本，访问父页面 DOM 被隔离。
4. 点击“编辑源码”，用真实 CodeMirror 修改，再保存。
5. 在模拟宿主的附件存储表面验证更新内容和哈希，再刷新浏览器验证持久化与重新挂载。
6. 下载修改件并检查内容；下载原件并检查原始内容未改。
7. 额外覆盖未保存关闭确认、恢复草稿、哈希冲突不覆盖、顶层导航被阻止，以及预览草稿不保存附件。

另有单元/集成回归覆盖：GBK/UTF16/BOM、伪编码属性、读取中版本变化、跨笔记拒绝、导入中笔记切换、部分上传失败资源恢复、待同步资源拒绝、笔记 ID 别名、复制笔记后的附件归属、过期草稿基线、撤销后清草稿、卸载面板迟到保存不清除新面板草稿、生命周期清理。

## 真实 EdgeEver 验收（尚未执行）

1. 启动本地服务器，用 `http://127.0.0.1:4173/dist/manifest.json` 安装，核对名称/作者/权限并启用。
2. 打开一篇已同步的普通笔记，进入编辑，导入项目中的 `demo/sample.html`，保存笔记。
3. 关闭面板，在普通阅读视图验证默认预览和页面按钮；点击编辑，改一句文字并保存。
4. 重开笔记/重启宿主，确认修改仍在；导出工作件、原件，分别确认新旧文字。
5. 用另一窗口/设备修改工作附件，确认旧快照保存被拒绝，且旧源码能导出。
6. 模拟离线/同步失败，确认错误明确、源码保留，未宣称云端已保存。
7. 复制带 HTML 块的笔记，确认预览/编辑使用复制后的资源，而不修改原笔记附件。
8. 禁用/启用插件，确认嵌入块生命周期、附件与草稿恢复符合预期。

本地测试不替代上述实际宿主步骤。浏览器本地网络策略、真实同步、桌面桥、宿主 CSP 和样式仍需实机确认。公开分享页/原生手机端不支持此交互插件。恢复草稿尚无跨窗口独占机制，重要修改应分别导出。

## 重跑

```powershell
cd edgeever-html-knowledge
npm ci
npm run check
npm audit
```

无 Playwright 浏览器时先执行 `npx playwright install chromium`。`npm run dev` 可手动打开开发演示；测试自动管理自己的服务器与浏览器，不需要连接远程服务或登录。
