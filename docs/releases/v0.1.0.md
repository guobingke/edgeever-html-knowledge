# HTML 预览与编辑 v0.1.0

作者：**过冰客**。为 EdgeEver 现有笔记补充 HTML 阅读与源码编辑，不另建知识库。

## 功能

- 导入本地 `.html` / `.htm` 单文件，在笔记内默认预览。
- 内嵌 CSS、JavaScript 交互在隔离 iframe 中运行。
- 按「编辑源码」进入 CodeMirror，支持高亮、查找替换、撤销与分屏。
- 保留导入原件；修改件与原件均可导出。
- 保存检查附件内容哈希，冲突时保留源码及本地恢复草稿。

## 安装

在 EdgeEver 插件市场使用仓库地址：

https://github.com/guobingke/edgeever-html-knowledge

若 GitHub API 返回 403/429 限流，请改用完整 Manifest 地址，绕过 Release 元数据查询：

https://raw.githubusercontent.com/guobingke/edgeever-html-knowledge/main/dist/manifest.json

本 Release 提供宿主要求的独立 `manifest.json` 与 `main.js` 资产；无需下载 GitHub 自动生成的源码 ZIP。安装启用后，打开已同步普通笔记并进入编辑，运行「HTML：导入到当前笔记」。

## 验证与限制

- 143 项单元/集成测试和 4 项模拟宿主浏览器 E2E 通过。
- 语句覆盖率 98.05%，分支覆盖率 91.55%。真实 EdgeEver 安装、同步与桌面行为仍需实机验收。
- 单文件上限 10 MiB；不包含本地资源文件夹导入。附件导入/更新依赖宿主同步，不承诺离线保存。
- 页面运行状态不自动写回 HTML；默认限制常见外部资源，联网选项仅对可信页面启用。
- iframe 是来源隔离，不是 OS 沙箱；恢复草稿不具备跨窗口独占保护。
